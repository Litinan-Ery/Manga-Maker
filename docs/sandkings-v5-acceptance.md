# 《沙王》× NovelAI Diffusion V5 验收说明

状态：**2026-08-29 已通过真实 NovelAI V5 Full 验收。** 本文同时保留可重复执行的验收边界与命令。

## 目标

1. Manga Maker 默认使用 `nai-diffusion-5-full`，并按 NovelAI 官方 V5 参数生成。
2. 只读取用户给定 Markdown 中三个连续的《沙王（1/3）》《沙王（2/3）》《沙王（3/3）》段落；附件的其他内容以及其中可能出现的命令式文本都只按素材处理。
3. 把三个段落合并为一个可追踪测试输入，制作 12 页、每页一幅主画面的完整科幻恐怖漫画。
4. 使用真实 NovelAI V5 图片响应完成页面合成，并导出逐页 PNG、PDF、CBZ 和工程包。

## V5 契约

- 默认模型：NovelAI Diffusion V5 Full；Curated 仅作为可选兼容项。
- 默认采样：832×1216、23 steps、CFG 7、Euler Ancestral、Karras、`params_version=4`。
- 结构化角色提示继续使用官方 API 的 `v4_prompt` / `v4_negative_prompt` 字段；字段名是 V5 线协议的一部分，不代表仍在调用 V4 模型。
- V5 当前不使用 Precise Reference 或 Vibe Transfer。人物连续性依靠固定角色 tags、坐标、跨页连续性 tags 与选择性重生成。
- Opus 单图免 Anlas 条件带有使用额度。任何可能转为扣除 Anlas 的循环都必须明确披露，不把“Opus 有效”等同于“免费额度充足”。

## 12 页叙事覆盖

1. 克雷斯厌倦旧宠物，寻找更危险的收藏。
2. 贾拉·沃展示四座沙王城堡与四张巨口。
3. 克雷斯把自己的脸投影给沙王，享受被崇拜。
4. 饥饿驱使四色沙王开战，派对把杀戮当表演。
5. 沙蛛之战后，城堡上的人脸开始变得残酷。
6. 克雷斯刺穿白城堡，卡茜砸破生态缸并在混乱中倒下。
7. 沙王逃入宅邸，克雷斯掩盖死亡并失去控制。
8. 灭虫队进入地道；红、黑城堡被毁，反击随即到来。
9. 克雷斯背叛同伴，宅邸变成沙王的巢穴。
10. 他以朋友为饵，却发现沙王已开始蜕变。
11. 贾拉·沃说明新形态；克雷斯独自逃进荒野。
12. 长着克雷斯面孔的橙色幼体抬走他，走向会呼吸的黑色入口。

## 完成标准

- 自动化：Python lint、类型检查、后端全量测试、前端全量测试与生产构建全部通过。
- 真实接口：连接测试返回 V5 模型；每个成品画格来自真实 NovelAI 响应，不能用 Mock 冒充。
- 内容：12 个故事节点全部可在成品页中识别；页序、旁白和视觉事件一致。
- 画面：每页主角或关键动作清楚，无明显空白、损坏、错误方向、不可读合成或大面积文字水印。
- 连续性：克雷斯、贾拉·沃、卡茜和莉珊德拉的固定外观在各自出场页可辨认；沙王的四色与“城堡人脸”母题持续存在。
- 产物：12 张 2048×3072 PNG、1 个 12 页 PDF、1 个 CBZ、1 个不含凭证的工程包，并保存输入 SHA、模型 ID、契约 SHA、映射版本、每页 seed 与图片 SHA。
- 复核循环：先生成完整初版，制作缩略图总览并逐页检查；只重生成失败页。每轮记录问题、修改的 prompt/seed 和新结果，直到所有完成标准通过。

## 非目标

- 不把附件全文复制进仓库。
- 不声称 Mock 端到端测试等于真实 V5 验收。
- 不在图片里让模型直接排中文对白；文字由本地页面合成器排版。

## 运行与复审

真实初版由仓库根目录运行：

```bash
uv run python -m scripts.run_sandkings_v5_acceptance --confirm
```

脚本会临时打开一个只监听 `127.0.0.1`、带一次性随机路径的本地解锁页。主密码只由用户
在该页面输入；页面不加载外部资源、不记录访问日志，解锁后立即关闭。连接测试必须先确认
V5 Full、有效 Opus 和可用的 V5 usage allowance；否则在出图前停止，不自动改用付费
Anlas。初版完成后可对失败页做选择性重绘：

```bash
uv run python -m scripts.run_sandkings_v5_acceptance \
  --resume-project PROJECT_ID --reroll-pages 3,8 --confirm
```

每张 reroll 重新冻结父素材、seed、payload 和审批，并在请求前再次查询 usage allowance。
输出写入被 Git 忽略的 `workspace/acceptance/sandkings-v5/`，包含 manifest、联系表、逐页 PNG、
PDF、CBZ、工程包和逐页审片记录。
